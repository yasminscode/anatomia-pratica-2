# Anatomia Prática 2 — Ombro, dorso e plexo braquial

Quiz estático para treinar identificação e anatomia funcional de 7 estruturas:
1. Deltoide
2. Serrátil anterior
3. Peitoral menor
4. Trapézio
5. Latíssimo do dorso
6. Manguito rotador
7. Plexo braquial

São 2 questões por estrutura (14 no total), com alternativas embaralhadas, correção imediata e pontuação.

## Publicação
Este repositório inclui um workflow do GitHub Actions em `.github/workflows/pages.yml` para publicar automaticamente o site no GitHub Pages quando houver push na branch `main`.

Se ainda não estiver ativo:
1. Abra **Settings → Pages**.
2. Em **Build and deployment**, selecione **GitHub Actions** como source.
3. Acesse **Actions** e aguarde o workflow terminar.
4. O site ficará disponível em https://yasminscode.github.io/anatomia-pratica-2/

## Nota sobre as imagens
As ilustrações incluídas são esquemáticas, criadas para apoiar a identificação por número. Não são fotografias das peças originais enviadas no arquivo RAR. Confira os detalhes anatômicos com o material da disciplina.
